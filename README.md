# Perfume Refill Sales Tracker

A web app for tracking sales, stock and expenses in a perfume refill business.

**Live demo:** https://markwaithaka93-sys.github.io/perfume-refill-sales-tracker/

## Features
- Owner and staff logins with different permissions
- Sales recording
- Stock management with low-stock alerts
- Product catalog with categories and photos
- Expense tracking
- Reports for the owner
- Daily automatic backups plus JSON export/import

## Built with
HTML, CSS and vanilla JavaScript. Data is stored in the browser (localStorage).

## Demo notes
This is a demo. Data is stored only in your own browser, so it is not shared between devices, and passwords are not securely stored. Please use test data only. The login screen shows the default demo login.
